**Track:** Design & Brand | **Pricing:** NGN 35,000 / $49 USD

### 1. Course Overview & Target Audience
Digital product design is being revolutionized by AI-accelerated workflows. This course takes learners through a complete 48-hour product design sprint using Figma AI: scoping problems, conducting user research synthesis, generating competitive user flows, creating high-fidelity wireframes with Figma First Draft, designing interactive prototypes, and converting designs into functional no-code database applications.

**Who This Course Is For:**
- UI/UX designers looking to supercharge their prototyping and wireframing velocity with Figma AI.
- Product managers and startup founders wanting to design and test functional app concepts in days.
- Graphic and web designers transitioning into high-demand product and interaction design roles.
- Learners wanting to bridge the gap between visual UI design and functional no-code application architecture.

**What You Will Produce:**
- A full mobile/web app design system with responsive auto-layout components in Figma.
- An AI-generated user research dossier with empathy maps, user personas, and competitor flowcharts.
- A multi-screen interactive Figma prototype with micro-interactions and realistic navigation states.
- A functional no-code application connected to a live database using Buzzy/Locofy.

#### Lesson 1: Problem Scoping & Product Discovery with AI
- **Timestamp:** `00:00` - `01:40` (0s to 100s)
- **Summary & Notes:** Introduces the 48-hour AI product sprint methodology. Teaches how to take an ambiguous user problem, use AI prompting to articulate user pain points, define product requirements, and structure a sprint schedule.
- **Practical Activity:** Write a 1-page Product Problem Statement defining target users, core job-to-be-done, and measurable success criteria.
- **Knowledge Check / Reflection:** Why does rapid AI-assisted problem validation save weeks of wasted UI design effort?

#### Lesson 2: AI-Assisted User Research & Live Interview Analysis
- **Timestamp:** `01:40` - `07:32` (100s to 452s)
- **Summary & Notes:** Demonstrates conducting user research and analyzing user interview transcripts with AI. Shows how to prompt LLMs to extract pain point themes, emotional friction points, feature wishlists, and user mental models.
- **Practical Activity:** Feed a user interview transcript into an AI model to generate an Empathy Map and prioritized feature list.
- **Knowledge Check / Reflection:** How does AI transcription analysis prevent designer bias when synthesizing qualitative interview data?

#### Lesson 3: Competitive Benchmarking, User Flows & Architecture Mapping
- **Timestamp:** `07:32` - `09:11` (452s to 551s)
- **Summary & Notes:** Covers competitor teardowns and information architecture. Uses AI to analyze competitor UX patterns (from Mobbin), identify friction points in their flows, and map out a streamlined end-to-end user flowchart.
- **Practical Activity:** Design a 6-step user journey flowchart mapping every screen state from onboarding to core task completion.
- **Knowledge Check / Reflection:** What are the essential screen states (empty, loading, error, success) that novice UI designers frequently forget?

#### Lesson 4: Rapid Wireframing & Screen Generation with Figma First Draft AI
- **Timestamp:** `09:11` - `13:21` (551s to 801s)
- **Summary & Notes:** Masterclass on using Figma AI's First Draft. Demonstrates generating full UI screen layouts from natural language prompts, adjusting component hierarchies, styling auto-layout frames, and establishing consistent typography and color design tokens.
- **Practical Activity:** Use Figma AI to generate 4 core application screens (Home, Detail, Form Input, User Profile), then refine styling with custom design tokens.
- **Knowledge Check / Reflection:** Why must AI-generated wireframes be manually adjusted for visual hierarchy, contrast, and spacing?

#### Lesson 5: Interactive Prototyping & Micro-Interaction Design with AI
- **Timestamp:** `13:21` - `13:51` (801s to 831s)
- **Summary & Notes:** Covers wiring screen transitions, smart animations, interactive component variants (buttons, inputs, bottom navigation bars), and modal overlays to create a realistic, clickable prototype.
- **Practical Activity:** Wire all 4 app screens into an interactive prototype with smart animate transitions and clickable navigation tabs.
- **Knowledge Check / Reflection:** How do realistic micro-interactions improve the quality of user feedback during usability testing?

#### Lesson 6: Automated UI Markup & No-Code Component Binding
- **Timestamp:** `13:51` - `15:11` (831s to 911s)
- **Summary & Notes:** Demonstrates using no-code plugins (Buzzy/Locofy) to automatically parse Figma auto-layout layers, tag them into functional components (forms, repeaters, action buttons), and prepare them for database binding.
- **Practical Activity:** Run automarkup on your Figma screens and verify that all text fields and buttons are tagged correctly as functional components.
- **Knowledge Check / Reflection:** What auto-layout naming conventions are required to make automated code generation clean and predictable?

#### Lesson 7: Database Schema Generation & Dynamic Data Binding
- **Timestamp:** `15:11` - `18:54` (911s to 1134s)
- **Summary & Notes:** Teaches how to prompt AI to generate relational database tables matching the UI data needs, create collections, configure data types, and bind live data fields directly to the Figma layout.
- **Practical Activity:** Generate a database schema (Users, Tasks/Items, Categories) and bind live sample data records to your UI repeating lists.
- **Knowledge Check / Reflection:** Why is designing UI with real, variable-length database content essential for testing edge-case text overflow?

#### Lesson 8: End-to-End Usability Testing, Quality Assurance & Design System Delivery
- **Timestamp:** `18:54` - `21:01` (1134s to 1261s)
- **Summary & Notes:** Final assembly and validation. Demonstrates testing the live functional app on mobile devices, checking responsive breakpoints, conducting accessibility contrast audits (WCAG 2.1 AA), and exporting design system assets.
- **Practical Activity:** Run a live prototype test on a mobile device, conduct a color contrast accessibility check, and document any UX friction points.
- **Knowledge Check / Reflection:** What are the final deliverables a product designer must hand over to ensure engineering builds the product accurately?

### 6. Written Learning Materials & Quality Assurance
**Actionable Verification Checklist:**
- [ ] User problem statement and empathy map completed.
- [ ] Information architecture and user flow mapped.
- [ ] Figma AI First Draft screens generated and converted to Auto-Layout.
- [ ] Design system tokens (colors, typography, spacing) codified.
- [ ] Interactive prototype wired with Smart Animate.
- [ ] Database schema created and bound to dynamic UI elements.
- [ ] WCAG 2.1 AA accessibility contrast verified.

**Common Pitfalls & Fixes:**
- **Mistake:** Designing without Auto-Layout
  - **Correction:** Placing static frames without auto-layout, causing layouts to break when text length changes. Fix: Always build frames with Auto-Layout enabled.
- **Mistake:** Ignoring empty and error states
  - **Correction:** Designing only the 'happy path' with perfect data. Fix: Always design empty-state illustrations and error message banners.
- **Mistake:** Failing accessibility contrast standards
  - **Correction:** Using light grey text on white backgrounds. Fix: Verify 4.5:1 minimum contrast ratio for all body text.
- **Mistake:** Overcomplicating the user flow
  - **Correction:** Requiring 6 clicks to complete a simple action. Fix: Use AI flow analysis to eliminate redundant steps.
